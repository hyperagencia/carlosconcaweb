# assets/ — bandeja de entrada

Deja aquí los archivos que vayas reuniendo (logos, fotos, íconos, PDFs). Claude los
clasifica después: lo que es parte del diseño va a `web/public/` y se sirve con
`next/image`; lo que edita el profesor (retrato, CV, imágenes de páginas) se sube a Sanity.

| Carpeta | Para qué |
|---|---|
| `logos/` | Logo de Carlos Conca (claro y oscuro), logo FCFM, favicon |
| `fotos/` | Retrato, fondo del hero, fotos de décadas / áreas de investigación |
| `iconos/` | Íconos SVG (tarjetas de cifras, flechas, etc.) |
| `documentos/` | CV en PDF y otros descargables |
| `otros/` | Lo que no encaje en las anteriores |

Sugerencias: nombres en minúsculas y con guiones (`retrato-carlos-conca.jpg`), SVG para logos
e íconos, y la foto original en la mejor resolución disponible (el sitio la optimiza).
